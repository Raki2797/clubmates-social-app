## Face Verification Models

`minifasnet_v2.onnx` is used for verification-selfie liveness checks only.

Source: `garciafido/minifasnet-v2-anti-spoofing-onnx` on Hugging Face.
License: Apache-2.0.

Runtime InsightFace weights for SCRFD detection and ArcFace embeddings are downloaded into the configured face model cache (`FACE_VERIFICATION_DEEPFACE_HOME`) on first use.
